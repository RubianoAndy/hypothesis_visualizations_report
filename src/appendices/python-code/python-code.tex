    Los tamaños de efecto de la Tabla \ref{efectos} aplican directamente las
    ecuaciones (\ref{cohend}) a (\ref{rdetectable}) sobre las salidas anteriores y
    no requieren comentario adicional. No ocurre lo mismo con los contrastes
    robustos de la Sección \ref{subsec_robustez_resultados}: ni el ANOVA de Welch ni
    el post-hoc de Games-Howell están disponibles en \textit{SciPy} o
    \textit{statsmodels}, por lo que se programaron a partir de sus formulaciones
    originales. La verificación cruzada de la Tabla \ref{verificacion} adquiere aquí
    especial valor, porque compara dos implementaciones escritas de forma
    independiente y no dos bibliotecas que podrían compartir su procedencia.
